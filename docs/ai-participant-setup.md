# AI 参加者 (ChatGPT デスクトップ音声) セットアップガイド — Windows

収録モードに「人間2名 + ChatGPT音声」の3者ポッドキャスト収録を追加する機能の、
ホストPC（Windows 11 + Chrome）での音声ルーティング手順。

アプリは OS レベルの音声しか扱わない。OpenAI API・ChatGPT の認証情報は一切使わない。

## 必要なもの

- ChatGPT デスクトップアプリ（音声モードが使えるプラン）
- VB-CABLE **2本**: [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)（CABLE-A/B、または無印 + A&B 拡張）
- **ヘッドホン必須**（スピーカーは音響回り込みの原因になるため禁止）

## 配線図

```
【ChatGPT の声を取り込む経路】
ChatGPT デスクトップ [出力デバイス = CABLE-A Input]
  → CABLE-A Output → 本アプリ「AI 音声ソース」で選択
       ├→ 録画ミキサー（自動）
       ├→ LiveKit 配信（リモート参加者が聴く・自動）
       └→ ホストのヘッドホンモニタ（自動）

【ChatGPT に聞かせる経路】
本アプリ「ChatGPT への送出先」= CABLE-B Input
  （アプリ内で「あなたのマイク + 相手の声」だけをミックスして送出。
   AI 自身の声は構造的に混ざらない）
  → CABLE-B Output = ChatGPT デスクトップ [入力デバイス]
```

## 手順

1. VB-CABLE A/B をインストールし、Windows サウンド設定で **全デバイスを 48000 Hz に統一**
   （サンプルレート不一致は音割れ・ノイズの原因）。
2. ChatGPT デスクトップの設定で **出力 = CABLE-A Input / 入力 = CABLE-B Output** を選択。
3. 自習室の収録モードに入り、StudioBar の 🤖 ボタンからセットアップを開く。
4. 「AI 音声ソース」= **CABLE-A Output** を選択。ChatGPT に何か話させ、レベルメーターが
   反応することを確認。
5. 「ChatGPT への送出先」= **CABLE-B Input** を選択。
6. **プリフライト（自己ループ検査）を実行**: ChatGPT に話させながら検査ボタンを押す。
   「AI の声が送出先に漏れていない」ことが確認されると合格。
   不合格の場合は配線（特に Windows の「このデバイスを聴く」設定が CABLE 間を
   繋いでいないか）を見直す。
7. 「AI 参加者を有効にする」を押す。ステージ下段に AI タイルが表示され、
   ChatGPT の発話でアバターが speaking 状態になる。
8. **参加中のメンバーにページの再読み込みを依頼**（AI タイルは新しい画面でのみ表示される）。
9. 録画開始。**AI の有効化は必ず録画開始前に行う**（録画中の有効化は不可）。

## 動作確認チェックリスト（収録前 毎回）

| 確認 | 期待 |
|---|---|
| 自分が話す | ChatGPT が反応する（CABLE-B 経由で届いている） |
| 相手が話す | ChatGPT が反応する |
| ChatGPT が話す | 自分のヘッドホンで聞こえる・相手にも聞こえる・AI タイルが speaking |
| ChatGPT に「今の音を繰り返して」 | 自分の声だけ繰り返す（AI 自身の声のループが無い） |

## トラブルシューティング

- **レベルメーターが動かない**: ChatGPT の出力デバイス設定がリセットされていないか確認
  （アプリ更新で既定デバイスに戻ることがある）。
- **「音声解析が停止中」表示**: 画面のどこかをクリックすると解除される（ブラウザの
  autoplay 制限）。
- **AI タイルが「⚠ 音声ソース切断」**: CABLE デバイスが無効化された。デバイスを戻して
  セットアップ画面の「再接続」を押す。**録画は途切れず継続している。**
- **遅延が大きい/音質が悪い**: 48kHz 統一を確認。改善しない場合は Voicemeeter Banana に
  よる低遅延ルーティング（上級者向け）を検討。
- **自分の声が二重に録れる**: 「AI 音声ソース」に物理マイクを選んでいないか確認
  （セットアップ画面に警告が出る）。

## 簡易構成（CABLE 1本・非推奨）

「ChatGPT への送出先」を未設定にし、ChatGPT の入力 = 物理マイクにする構成。
ChatGPT はホストの声しか聞けない（相手の発言はホストが復唱する運用）。
ソロ + AI の収録やテストにはこれで十分。
