# 収録モードのスポットライト

収録バーの「レイアウト」から選択します。

- **スポットライト**: 「スポットライト対象」で選んだ1名を大きく固定します。
- **スポットライト＋全参加者を下部に表示**: 上に対象、下に全参加者を表示します。下部には対象本人と有効なAI参加者も含みます。ホストは下部のタイルをクリックして対象を変更できます。
- **スポットライト解除**: 横並び2分割に戻ります。他のレイアウトを直接選ぶこともできます。

選択は既存の収録設定と同じルームmetadata経由で参加者に配信されます。発話や画面共有の開始では対象は変わりません。対象の退出時は再参加を待つ表示になり、ホストが別の参加者へ変更できます。

下部列は16:9の収録ステージ内にあり、録画に含まれます。従来の「視聴者を下段に表示」は録画範囲外の表示です。全参加者を下部に表示するレイアウトでは、重複する範囲外の列は表示しません。

## ローカル検証

```powershell
node node_modules/next/dist/bin/next dev --port 3107
# 別のターミナル
node scripts/verify-spotlight.mjs
```

開発専用の `/dev-preview/spotlight` で実コンポーネントを検証します。本番では404です。実通話への接続や音声入力は使用しません。

実機で残る確認: ホストと別端末間のmetadata同期、後入室・再接続、実カメラ映像と保存した録画での構図確認。
